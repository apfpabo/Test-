# Iron Meridian — notes for agents

- **Read [`docs/CREATIVE_DIRECTION.md`](docs/CREATIVE_DIRECTION.md) before any design, art, balance or feature work.** It is the project owner's north star. Never edit its text without their instruction.
- [`docs/ROADMAP.md`](docs/ROADMAP.md) holds the gap analysis, the owner's standing feedback (grounded rather than arcade, Rule the Waves 3 art reference, no boarding) and the order of work. Keep it up to date as features land.
- **The game is moving to Godot 4** (owner's decision), battle first. Two builds live side by side until the port is done:
  - `godot/` is the Godot 4.3 project (GDScript, GL Compatibility renderer). It holds the battle screen and a battle setup screen. The simulation is in `godot/scripts/battle_sim.gd` (no drawing); `battle.gd` draws it and handles input; `battle_hud.gd` is the HUD. Shaders are in `godot/shaders/`.
  - `src/game.html` is the browser build and still holds the campaign (world map, ports, missions). Run `./build.sh` to produce the standalone `index.html`, and commit both. Don't add new features here; port them.
- Ship art and game data are baked from the browser build: `node tools/bake_assets.js` renders every design, paint scheme, mount and effect texture into `godot/assets/` and exports `godot/data/game_data.json` and `sprites.json`. Re-run it after changing designs, weapons, paint schemes or plan drawing in `src/game.html`, then let Godot re-import (`godot --headless --path godot --editor --quit`).
- Godot checks: `godot --headless --path godot res://tests/run_presets.tscn` plays every preset battle to the end and prints the outcomes; `xvfb-run -a godot --path godot --rendering-driver opengl3 res://tests/shot_battle.tscn -- <preset> <out dir>` saves screenshots. GDScript can't infer types from Dictionary values, so declare those variables untyped or with an explicit type.
- Ships, factions and names are fictional, though ships are modelled on real designs. Do not copy assets from Starsector, Rule the Waves or any other game.
- The world map uses 1 map unit = 0.05°, equirectangular projection from 82°N to 78°S, wrapping east-west. Always use `wdx`, `mdist` and `mang` for map distances and angles, never raw `dist`. Use `onLand` for collision, and `setCourse` + `routeMove` to move fleets.
